# Honest — versió Vignelli

Redisseny de la web d'Honest amb el mètode de Massimo Vignelli (Vignelli Canon):
retícula de 12 columnes, Helvetica + Bodoni, negre / blanc / vermell, filets i bandes,
contrast d'escala i molt de blanc. HTML estàtic + un sol CSS, sense JavaScript ni imatges
de tercers: cada projecte té una forma geomètrica pròpia (identitat i diversitat).

Obrir `index.html` directament al navegador o: `python3 -m http.server 8000`.
