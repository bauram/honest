# Honest — web (Vignelli × Honest)

Redisseny de la web d'Honest aplicant el mètode de Massimo Vignelli (Vignelli Canon) a la identitat
d'Honest: es respecta el logotip policrom (equity) i els quatre colors passen a ser un codi de senyals,
un per línia (blau: estudi creatiu · vermell: art contemporani · groc: espais de creació · verd: acció comunitària).

- Retícula de 12 columnes, Helvetica + IBM Plex Mono, tinta blau nit #1f3350.
- Continguts i fotografies de la Memòria anual 2025.
- HTML estàtic + un sol CSS, sense JavaScript.

Obrir `index.html` al navegador o `python3 -m http.server 8000`.
